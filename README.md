# Server Monitor CLI

A Linux server monitoring tool built with C# and .NET.

## Features

- CPU Monitoring
- Memory Monitoring
- Disk Monitoring
- Uptime Monitoring
- Report Generation
- Watch Mode

## Technologies

- C#
- .NET
- Linux
- /proc/stat
- /proc/meminfo

## Usage

dotnet run

dotnet run -- --report

dotnet run -- --watch
